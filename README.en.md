# Short link · go.zyx0407.com

`go.zyx0407.com` does one thing: open it and you land on [zyx0407.com](https://zyx0407.com/).

- **Why it exists**: the QR code on the back of the physical card carries this short domain. Changing the destination later means editing this one page — the card never has to be reprinted.
- **How it works**: one static page, no dependencies, no build step. A script redirects immediately, `<meta refresh>` is the fallback, and a plain link stays clickable when scripts are disabled.
- **Scope**: no content and no tracking here. Everything lives on the main site.
